## 🚀 Getting Started

### Prerequisites

You only need a modern web browser (Chrome, Firefox, Edge, Safari).

### Running Locally

1. Clone the repository:
```bash
git clone [https://github.com/dianemahusay/worst_login.git](https://github.com/dianemahusay/worst_login.git)

```


2. Navigate to the project folder:
```bash
cd worst_login

```


3. Open `login.html` directly in your browser:
* Double-click `login.html`, or
* Drag and drop `login.html` into an open browser window.
